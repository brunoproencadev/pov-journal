# POV — Point of View | Digital Newspaper Platform

A modern digital newspaper platform built with Next.js 15, TypeScript, Tailwind CSS v4, Prisma, and NextAuth v5.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4 + Editorial CSS design system
- **Auth**: NextAuth v5
- **ORM**: Prisma
- **Database**: PostgreSQL
